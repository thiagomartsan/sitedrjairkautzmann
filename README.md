# Dr. Jair Kautzmann Odontologia | Premium V3

Landing page demonstrativa em HTML, CSS e JavaScript vanilla, com imagens já inseridas.

## O que mudou nesta versão

- fotografias premium inseridas no site
- novo retrato do Dr. Jair em duas variações consistentes
- imagens de estética, ortodontia e consultório
- correção do hover do card de estética
- tipografia Onest + Newsreader
- headline do hero reduzida e mais legível
- Instagram e Facebook também no menu superior
- copy revisada para linguagem mais clínica, humana e objetiva
- remoção de travessões longos na copy
- seção regional simplificada para Blumenau, Indaial e Vale do Itajaí
- visualizador interativo de alinhamento com controle deslizante e inclinação 3D
- botões e componentes arredondados preservando leitura e sobriedade

## Arquivos

- `index.html`: versão padrão para deploy
- `css/styles.css`
- `js/main.js`
- `assets/images/`: imagens já vinculadas no HTML
- `index-standalone.html`: versão de arquivo único com CSS, JS e imagens incorporados

## WhatsApp

Edite `WHATSAPP_NUMBER` no topo de `js/main.js`. Na versão standalone, pesquise pelo mesmo nome dentro do próprio HTML.

## Redes sociais

Os ícones de Instagram e Facebook aparecem no header, hero e footer. Os links seguem como placeholders até serem definidos.

## Observação sobre o visualizador

O visualizador de alinhamento é ilustrativo e não representa previsão clínica. Foi criado como elemento interativo de apresentação do planejamento digital.
